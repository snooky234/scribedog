# ScribeDog Documentation

This is the long version of the [README](../README.md): how each feature
works, what the settings do, and how to get unstuck. You do not need to read
it front to back. Pick the page for the thing you want to do.

## Getting started

- [Installation and first steps](getting-started.md): download, portable
  build, the Windows SmartScreen warning, opening your first folder.
- [Setting up AI](ai-setup.md): local model runners, cloud providers, and
  which model size to pick.

## Writing and organizing notes

- [Writing](writing.md): the WYSIWYG editor, drawings, highlighting, heading numbering,
  Zen mode, copy and paste.
- [Notes and your vault](notes-and-vault.md): the file tree, folder notes,
  linked notes, the details panel, pinned notes, auto-save, version history.
- [Import and export](import-export.md): bring Word, PDF, HTML and images in,
  send PDF, DOCX, ODT and HTML out.
- [Voice input](voice.md): dictate into a note or an AI prompt, fully offline.
- [Customizing](customizing.md): themes, the theme builder, languages,
  keyboard shortcuts.

## Working with AI

- [AI writing](ai-writing.md): rewrite and insert text in place, review
  changes before they land, spelling and grammar check.
- [AI chat](ai-chat.md): the agent in the side panel, edits across your whole
  vault, plans, and your own assistants.
- [Knowledge base](knowledge-base.md): let the AI answer from your own notes,
  and attach single files as context.

## Sync, privacy and the server

- [Sync and mobile access](sync-and-mobile.md): reach your notes from other
  devices.
- [Privacy](privacy.md): what stays on your machine and what does not.
- [Server Edition](../server/docs/README.md): run ScribeDog on your own
  server and use it from any browser, phone or tablet.
